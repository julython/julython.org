# Help

## Purpose

Serve static informational pages: help, about, and privacy.

## Requirements

### Requirement: Static pages

The system SHALL serve the help, about, and privacy pages at their respective routes.

#### Scenario: Help page

- **WHEN** the help route is requested
- **THEN** the help page is rendered within the site layout

#### Scenario: About page

- **WHEN** the about route is requested
- **THEN** the about page is rendered within the site layout

#### Scenario: Privacy page

- **WHEN** the privacy route is requested
- **THEN** the privacy page is rendered within the site layout
